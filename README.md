# Saqf | سقف — Landing Page

Frontend-only one-page landing site for **Saqf Property Collective**.

## Stack

- Vite + React + TypeScript
- English / Arabic with RTL support
- No backend

## Brand colors

| Token | Hex |
|-------|-----|
| Navy  | `#202350` |
| Gold  | `#dbb382` |
| White | `#fffeff` |

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Notes

- Language preference is stored in `localStorage` (`saqf-lang`)
- Hero uses a looping background video (Pexels) with a dark overlay
- Logo: `public/images/saqf-logo.png`
